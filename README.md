
# Task 39 – Basic Power BI Import

## Project Overview
This project demonstrates basic data import and report creation using Microsoft Power BI.

## Objective
To import a dataset and create a simple one-page interactive report.

## Tools Used
- Microsoft Power BI Desktop
- Sample Superstore Dataset

## Visualizations Created
1. Sales by Category
2. Profit by Region
3. Monthly Sales Trend

## Workflow
1. Imported the Superstore dataset.
2. Cleaned and renamed the fields.
3. Created three visualizations.
4. Designed a one-page report.

## Outcome
Successfully created a basic Power BI sales analysis report.
